# 김예림 개인프로필 웹페이지

최종 반영 기준: 2026-09-30, Figma의 `203:1273` 섹션 및 빨간 수정 메모.
기존 프로젝트 파일 안에서 화면과 동작을 수정했습니다.

## 실행하기

1. ZIP 전체를 압축 해제합니다.
2. `aerim-portfolio/index.html`을 더블 클릭합니다. VS Code의 Live Server로 열어도 됩니다.
3. `My Computer`를 클릭하면 `portfolio/index.html`이 새 탭에서 열립니다.

별도 설치나 빌드 과정은 없습니다. 이미지와 폰트도 포함되어 있습니다.
`index.html` 파일만 따로 옮기지 말고, `css`, `js`, `img`, `fonts`, `portfolio` 폴더를 함께 보관하세요.
기존 폴더에 덮어쓸 경우, 개인적으로 수정한 파일은 먼저 따로 보관하세요.

## 반영한 동작

- **My Computer:** 앞서 만든 아이보리·딥 그린 포트폴리오를 새 탭에서 엽니다.
- **커서:** Figma 베리언트의 화살표가 기본이며, 마우스 왼쪽 버튼을 누르는 동안 손 모양으로 바뀝니다. 버튼을 놓거나 브라우저 창에서 초점이 벗어나면 기본 상태로 돌아갑니다. 터치 화면에는 커서를 표시하지 않습니다.
- **창 이동:** 메인 그림판과 Hello World의 파란 제목 표시줄을 드래그할 수 있습니다. 화면 밖으로 완전히 사라지지 않습니다. 제목 표시줄에 키보드 초점을 둔 후 방향키로도 움직일 수 있고, Home으로 위치를 초기화합니다.
- **팔레트:** 컬러칩을 누르면 메인 제목과 설명의 글자색이 바뀝니다. Edit는 위치와 색을 초기화합니다.
- **타이핑:** ABOUT ME, HOW CAN I HELP, SKILLS, DESIGN WORKS와 영문 슬로건이 한 글자씩 나타납니다. 제목 옆 아이콘은 타이핑이 끝날 때 나타납니다.
- **본문과 사진:** About 본문과 업무 설명은 스크롤할 때 등장합니다. 프로필 카드·사진 4장·스킬 창은 오류 창처럼 차례로 나타납니다.
- **작업물:** 팝업·포스터·배너는 일정 속도로 계속 흐릅니다. 마우스를 올리거나 키보드 초점을 두면 잠시 멈춥니다. 이전·다음, 일시정지·재생, 확대 보기도 가능합니다.
- **휴지통:** 현재 시안의 이미지 13장과 배치를 반영했습니다. 클릭한 이미지의 확대 창은 최대 680px로 제한합니다.
- **반응형:** 바탕화면에는 페이지 스크롤을 만들지 않고, 긴 내용은 팝업 안에서 스크롤합니다. 태블릿·모바일에는 별도 배치를 적용했습니다.
- **동작 줄이기:** 기기의 동작 줄이기 설정을 사용하면 타이핑·등장 효과와 자동 슬라이드를 멈추고 내용을 바로 표시합니다.

About는 `start → About me`, 작업물은 `My Documents`, 연락처는 `Inbox`에서 엽니다.
팝업은 닫기 버튼 또는 Escape로 닫습니다. 사진·스킬 창을 닫았으면 `창 다시 열기`로 복원할 수 있습니다.

## 현재 내용 기준

- 화면에 표시하는 이름은 현재 Figma와 두 번째 사이트의 **김예림 / YERIM KIM**을 따랐습니다. 프로젝트 폴더명은 기존 `aerim-portfolio`를 유지했습니다.
- About 프로필의 이메일은 시안의 네이버 주소, Contact의 이메일은 시안의 Gmail 주소입니다.
- 메인 Contact의 Git hub 칸은 현재 Figma에 주소가 없어 `—`로 표시합니다. 연결된 두 번째 사이트의 기존 GitHub 링크는 유지했습니다.
- 메인 `DetailPage`와 `projects` 폴더는 현재 Figma 섹션에 작품 이미지가 없어 기존 빈 목록을 유지했습니다. 파일을 넣으면 바로 표시할 수 있도록 구조를 준비해 두었습니다.
- 두 번째 사이트의 화면·문구·레이아웃은 기존 파일을 유지하고, 이미지와 폰트의 임시 외부 연결을 상대 경로로 바꿨습니다.
- 피그마 원본 파일은 변경하지 않았습니다.

## 수정할 파일

| 위치 | 내용 |
| --- | --- |
| `index.html` | 메인 창·프로필·메뉴·연락처 |
| `css/style.css`, `css/responsive.css` | 기본 화면 배치와 반응형 |
| `css/interactions.css` | 이번 수정 배치, 커서, 드래그, 팔레트, 확대창 크기 |
| `css/variables.css` | 공통 색상과 서체 |
| `js/main.js` | 시작 메뉴·각 창·확대 보기 |
| `js/interactions.js` | 커서 전환·창 이동·글자색 변경 |
| `js/motion.js`, `css/motion.css` | 타이핑·스크롤 등장·팝업 효과 |
| `js/data.js`, `js/gallery.js` | 작품 목록·슬라이드 속도·재생 |
| `img/profile/` | 현재 프로필 사진 4장 |
| `img/icons/cursor-*-64.png` | 실제 적용하는 64px 커서 두 장 |
| `img/icons/cursor-default.png`, `cursor-click.png` | Figma 커서 원본 |
| `portfolio/index.html` | My Computer에 연결한 두 번째 사이트 |
| `portfolio/css/style.css`, `portfolio/js/main.js` | 두 번째 사이트의 스타일·동작 |

My Computer의 연결 주소를 변경하려면 메인 `index.html`에서 `href="portfolio/index.html"`을 바꾸세요.
같은 탭에서 열려면 같은 링크의 `target="_blank"`를 제거하세요.
슬라이드 속도는 `js/data.js`의 `slideSpeed`, 타이핑 속도는 `js/motion.js`의 `typingStep`에서 조절합니다.

## 이미지와 글꼴

이미지는 기존 프로젝트의 개별 Figma 자산과 이번에 변경된 레이어의 내보내기 파일을 사용합니다.
화면 전체를 하나의 이미지로 대체하지 않았습니다. 텍스트·버튼·창은 HTML과 CSS로 구현했습니다.
폰트는 NeoDunggeunmo와 Pretendard이며 라이선스는 `fonts/`에 함께 있습니다.

## 확인한 항목

Chromium에서 로컬 `index.html`을 열어 확인했습니다.
- PC·태블릿·모바일의 320~1920px 화면과 가로 화면 배치
- My Computer의 새 탭 열기와 연결된 사이트의 이미지 19개 로딩
- 커서 전환, 두 창의 드래그, 확대·복원, 팔레트 색 변경
- 제목 타이핑, 스크롤 등장, 프로필 사진 4장의 순차 등장
- 갤러리 자동 이동·일시정지·이전/다음·확대, 휴지통 이미지 확대
- 동작 줄이기 설정과 모바일 팝업의 가로 넘침

검수 중 브라우저 실행 오류나 누락된 파일 요청은 없었습니다.
